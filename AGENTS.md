# AGENTS.md

## Project Overview

- Bun workspace for publishable OpenCode plugins in `packages/*`.
- Current packages:
  - `packages/opencode-bashkit/` - OpenCode v2 shell backed by a temporary Bashkit copy-on-write filesystem, with a Rust/N-API runtime. Linux x64 glibc only.
  - `packages/opencode-codebase-memory/` - integrates `codebase-memory-mcp` with project-root safety checks, startup indexing, and project tools.
  - `packages/opencode-gortex/` - OpenCode v2 Gortex MCP integration with project tracking, path scoping, and opt-in skills and community routing.
  - `packages/opencode-impeccable/` - native plugin port of pbakaus/impeccable: 24 design commands as `/impeccable-*`, typed tools backed by the upstream Rust engine, and a post-edit detector hook. Tracks upstream via `bun run sync` in the package.
  - `packages/opencode-improve/` - registers an `improve` advisor agent and `/improve` command backed by bundled audit-planning references.
  - `packages/opencode-worktrunk/` - Worktrunk (`wt`) git-worktree management plugin.
- Codebase Memory, Impeccable, Improve, and Worktrunk support OpenCode v1 (1.18.29+) and v2 through one default export. Bashkit and Gortex are v2-only.
- Root `README.md` is generated by `mise run readme` from package manifests and `scripts/update-readme.ts`. Do not hand-edit it.

## Generated And Ignored Files

- `README.md` is generated by `scripts/update-readme.ts`.
- `packages/*/dist/` is build output and ignored by git; do not edit generated files in `dist/`.
- Bashkit's `native/target/` is ignored build output; `native/Cargo.lock` is tracked and used by `--locked` builds/tests.
- Improve's `references/` and Impeccable's `vendor/impeccable/` plus `upstream-lock.json` are upstream snapshots managed by their sync scripts.

## Repo Conventions

- Keep edits scoped to the relevant package; shared root logic lives mostly in `scripts/`, workspace manifests, and release config.
- Use the checked-in Oxfmt/Oxlint configs, which extend Ultracite, and `.editorconfig`. Oxlint enables the core and anti-slop presets. hk also runs Knip, secret scans, workflow checks, and formatters for other file types. Avoid unrelated formatting churn when applying fixes.
- Preserve both `server()` (v1) and `setup()` (v2) behavior in dual-version packages and cover changes through the existing compatibility tests.

## Security

- Do not commit credentials or private config.
- Report vulnerabilities per `SECURITY.md` instead of opening a public issue.
